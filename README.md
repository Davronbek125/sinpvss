# SINOV SERTIFIQAT SERVIS (sinovss.uz)

«SINOV SERTIFIQAT SERVIS» MChJ rasmiy veb-sayti.

O'zbekiston Respublikasida qurilish materiallari va konstruksiyalarini akkreditatsiyadan o'tgan sinov laboratoriyasida sinash hamda Milliy sertifikatlashtirish tizimida sertifikatlash xizmatlari.

## 🏛 Akkreditatsiya va Litsenziyalar
- **Sertifikatlashtirish organi:** № `O'ZAK.MS.0029`
- **Sinov laboratoriyasi:** № `O'ZAK.SL.0154`
